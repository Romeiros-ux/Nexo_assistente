  📋 PRÓXIMOS PASSOS
================================================================================

1️⃣  COMMITAR ALTERAÇÕES
   
   Execute no terminal:
   
   git add .
   git commit -m "feat: configurações para deploy no Render"
   git push origin main

   ⚠️  IMPORTANTE: Verifique se .env NÃO foi commitado!
   
   Verificar: git status
   Se aparecer .env, execute: git rm --cached .env

2️⃣  CRIAR SERVIÇO NO RENDER

   • Acesse: https://render.com
   • Clique em "New +" → "Web Service"
   • Conecte seu GitHub
   • Selecione o repositório "Nexo_assistente"
   • O Render detectará automaticamente o render.yaml

3️⃣  CONFIGURAR VARIÁVEIS DE AMBIENTE

   No painel do Render, adicione em "Environment":
   
   NODE_VERSION                     = 18.19.0
   VITE_SUPABASE_URL               = https://bkssobleshobcwnnipak.supabase.co
   VITE_SUPABASE_PROJECT_ID        = bkssobleshobcwnnipak
   VITE_SUPABASE_PUBLISHABLE_KEY   = [COPIE DO ARQUIVO .env LOCAL]

4️⃣  CONFIGURAR CORS NO SUPABASE

   Após o deploy, você receberá uma URL (ex: https://nexo-assistente.onrender.com)
   
   • Acesse: https://supabase.com/dashboard/project/bkssobleshobcwnnipak
   • Vá em: Authentication → URL Configuration
   • Adicione a URL do Render em "Site URL" e "Redirect URLs"
   • Salve as alterações

5️⃣  TESTAR A APLICAÇÃO

   • Acesse a URL fornecida pelo Render
   • Teste login
   • Teste funcionalidade do chat
   • Verifique console (F12) para possíveis erros

================================================================================

1. PLANO FREE DO RENDER
   • O serviço hiberna após 15 min de inatividade
   • Primeiro acesso pode ser lento (~30s cold start)
   • Para melhor performance, considere Starter ($7/mês)

2. MONITORAMENTO
   • Logs do Render: Dashboard → Logs
   • Logs do Supabase: Dashboard → Logs
   • Monitore uso de créditos da API Lovable

3. SEGURANÇA
   • NUNCA commite o arquivo .env
   • Use .env.example para documentação
   • Rotacione chaves periodicamente

4. EDGE FUNCTIONS
   • Já estão deployadas no Supabase
   • Verifique se LOVABLE_API_KEY está configurada
   • Independentes do deploy do frontend

  🆘 SUPORTE
================================================================================

Problemas comuns e soluções:

❌ Build Falha
   → Verifique logs no Render
   → Confirme que todas as variáveis foram adicionadas

❌ Página em Branco
   → Abra console do navegador (F12)
   → Verifique variáveis VITE_*
   → Confirme CORS no Supabase

❌ Login Não Funciona
   → Verifique URL do Render nas configs do Supabase
   → Teste com usuário existente

❌ Chat Não Responde
   → Verifique LOVABLE_API_KEY nas Edge Functions
   → Teste Edge Functions no Supabase Dashboard
